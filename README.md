# CCNA Networking Project

This repository contains my CCNA networking project, built using **Cisco Packet Tracer**.  
It demonstrates practical skills in designing, configuring, and troubleshooting enterprise‑level networks.

## 🔹 Project Overview
- Designed and implemented a complete network topology in Cisco Packet Tracer.
- Configured **VLANs, trunking, HSRP, and routing protocols** for redundancy and efficiency.
- Documented configurations, diagrams, and troubleshooting steps.

## 🔹 Files Included
- `ccna project.pkt` → Packet Tracer topology file  
- `ccna project documentation.docx` → Detailed documentation with diagrams and explanations  

## 🔹 Skills Demonstrated
- Networking fundamentals (VLANs, routing, switching)  
- Cisco Packet Tracer configuration  
- Troubleshooting and documentation  

---

### ✅ How to Use
1. Download the `.pkt` file and open it in Cisco Packet Tracer.  
2. Review the documentation for configuration steps and explanations.  
3. Explore the topology to understand redundancy and routing setup.
